# SOC-Home-Lab-Wazuh-SIEM-i-Automatyzacja-Active-Response-
Domowe laboratorium SOC oparte na Wazuh SIEM i Sysmon. Projekt obejmuje konfigurację telemetrii na stacjach Windows/Linux, tworzenie własnych reguł detekcji oraz automatyzację reakcji na incydenty (Active Response). Udokumentowano scenariusze: ataki SSH Brute-Force i nieautoryzowaną manipulację kontami systemowymi.
